System Information

📊 Results Interpretation

If ALL tests fail (no sound):

  • ❌ Your Mac's notification/alert sounds are disabled
  • ❌ Check System Preferences → Sound → Alert volume
  • ❌ Check Do Not Disturb mode is OFF
  • ❌ Check System Preferences → Notifications → [Browser] → "Play sound" enabled

If Test 1 fails but Tests 2-3 work:

  • ⚠️ Browser notification sounds are disabled
  • ⚠️ Check browser notification settings
  • ⚠️ Grant notification permission

If all tests work here but ZeusChat doesn't:

  • ✅ Your system is fine!
  • ✅ Check ZeusChat console logs (F12) for errors
  • ✅ Make sure notification permission granted to ZeusChat
  • ✅ Hard refresh ZeusChat page (Cmd+Shift+R)
